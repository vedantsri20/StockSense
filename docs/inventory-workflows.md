 # StockSense Inventory Workflows

## 1. Receipts

1. Create receipt
2. Select supplier
3. Select product
4. Enter quantity
5. Validate receipt
6. Increase stock
7. Create stock ledger entry

## 2. Delivery Orders

1. Create delivery order
2. Select product
3. Enter quantity
4. Pick
5. Pack
6. Validate delivery
7. Decrease stock
8. Create stock ledger entry

## 3. Internal Transfers


1. Select source location
2. Select destination location
3. Select product
4. Enter quantity
5. Validate transfer
6. Decrease stock at source
7. Increase stock at destination
8. Create stock ledger entry

## 4. Stock Adjustments

1. Select product
2. Enter physical quantity
3. Compare with system quantity
4. Calculate difference
5. Update stock
6. Create adjustment ledger entry

## 5. Low Stock Alerts

1. Check current stock
2. Compare with minimum stock level
3. If stock is below minimum level
4. Generate low-stock alert
